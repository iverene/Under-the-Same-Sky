# 2D Sky View Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a persisted 2D/3D view toggle where a fixed, intro-styled illustrated 2D scene shows the same messages, landmarks, modals, search, Write/Wish, and sky themes as the 3D sky.

**Architecture:** Extract the existing R3F scene into a `Sky3D` child so WebGL unmounts when not in use; add a new DOM/SVG `Sky2D` rendered from the same `messages` state, placing objects by projecting their stored 3D positions. `NightSky` keeps all orchestration state and swaps scenes behind the shared overlays (ReadingCard, modals, HUD, TopBar, SearchPanel).

**Tech Stack:** React 19, Tailwind CSS v4, inline SVG/CSS (no new deps), localStorage, existing `SKY_THEMES`, Playwright/Puppeteer dev checks only.

## Global Constraints

- No new dependencies, no backend or schema changes, no test runner. Verification is `npx eslint` on touched files, `npm run build`, and browser checks. Do not add test infrastructure.
- Full-repo `npm run lint` has pre-existing errors in unrelated files — lint only touched files; never fix unrelated files.
- `Math.random` during render trips `react-hooks/purity` — use `mulberry32` / `hashString` from `sky2d/projection.js`, never `Math.random` in a component body.
- 3D is the default first impression. Persist the choice under localStorage key `utss.view` (`'2d' | '3d'`); `localStorage` failures fall back to `'3d'`.
- 2D art stays inline SVG/CSS — no image assets.
- Every 2D star/lantern is a real `<button>` with a ≥44px hit area and an `aria-label`; decorative layers are `aria-hidden`.
- All 2D motion must respect `prefers-reduced-motion`.
- Preserve 3D behavior exactly: selection, camera flights, reading card, outside-tap/Escape close, modals, themes, reset.
- Do not place `data-sky-surface` on the reading card or modals; it marks only the 2D clickable scene.

const KEY = 'utss.view';

export const readView = () => {
  try {
    return window.localStorage.getItem(KEY) === '2d' ? '2d' : '3d';
  } catch {
    return '3d';
  }

export const writeView = (view) => {
  try {
    window.localStorage.setItem(KEY, view === '2d' ? '2d' : '3d');
  } catch {
    // Private mode / storage disabled — the session still works, just unpersisted.

};

### Task 3: Projection + seeded starfield

**Files:**
- Create: `frontend/src/components/sky2d/projection.js`

**Interfaces:**
- Produces:

- Dependency-free (no `three` import) so it runs under plain Node.

- [ ] **Step 1: Create the module**

```js
// Deterministic helpers shared by the 2D scene. No three.js import: positions
// only need x/y/z, so plain objects and THREE.Vector3 both work.

export const mulberry32 = (seed) => () => {
  seed |= 0;
  seed = (seed + 0x6d2b79f5) | 0;
  let t = Math.imul(seed ^ (seed >>> 15), 1 | seed);
  t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
  return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
};

export const hashString = (value) => {
  let h = 2166136261;
  const s = String(value);
  for (let i = 0; i < s.length; i++) {
    h ^= s.charCodeAt(i);
    h = Math.imul(h, 16777619);
  }
  return h >>> 0;
};

const clamp = (v, min, max) => Math.min(max, Math.max(min, v));

const direction = (position) => {
  const x = Number(position?.x) || 0;
  const y = Number(position?.y) || 0;
  const z = Number(position?.z) || 0;
  const len = Math.hypot(x, y, z) || 1;
  return { x: x / len, y: y / len, z: z / len };
};

// Tiny deterministic offset so identical directions never stack exactly.
const jitter = (id) => (hashString(id) % 2001) / 1000 - 1; // -1 .. 1

export const starTo2D = (position, id) => {
  const d = direction(position);
  const azimuth = Math.atan2(d.x, -d.z);
  const elevation = Math.asin(clamp(d.y, -1, 1));
  const j = jitter(`star-${id}`);
  // Full-circle azimuth → width, so the whole stored sky spreads out
  // instead of piling against the edges.
  const x = ((azimuth + Math.PI) / (Math.PI * 2)) * 100 + j * 1.5;
  // Elevation band: low stars sit near the horizon, high stars near the top.
  const t = clamp((elevation + 0.2) / 1.65, 0, 1);
  const y = 62 - t * 56 + j * 1.2;
  return { x: clamp(x, 4, 96), y: clamp(y, 6, 62) };
};

export const lanternTo2D = (position, id) => {
  const { x = 0, z = 0 } = position || {};
  const azimuth = Math.atan2(Number(x) || 0, -(Number(z) || 0));
  const h = hashString(`lantern-${id}`);
  const xPct = ((azimuth + Math.PI) / (Math.PI * 2)) * 100;
  // Lanterns share one stored y, so stagger them vertically by id hash.
  const yPct = 45 + ((h >>> 8) % 1000) / 1000 * 27;
  return { x: clamp(xPct, 4, 96), y: clamp(yPct, 45, 72) };
};

export const messageTo2D = (message) => {
  if (message?.type === 'lantern') return lanternTo2D(message.position, message.id);
  return starTo2D(message?.position, message?.id);
};

export const makeStarfield = (seed = 20261019, count = 95) => {
  const rand = mulberry32(seed);
  return Array.from({ length: count }, () => ({
    x: +(rand() * 100).toFixed(2),
    y: +(rand() * 62).toFixed(2),
    size: +(rand() * 2 + 1).toFixed(1),
    delay: +(rand() * 4).toFixed(1),
    dur: +(2.5 + rand() * 3).toFixed(1),
    opacity: +(0.4 + rand() * 0.6).toFixed(2),
  }));
};
```

```jsx
import { useEffect, useMemo, useState } from 'react';
import { messageTo2D, makeStarfield } from './projection';
import { SKY_THEMES } from '../../three/themes';
import Moon2D from './Moon2D';
import Terrain2D from './Terrain2D';
import Star2D from './Star2D';
import Lantern2D from './Lantern2D';

const Sky2D = ({
  messages,
  selectedId,
  skyTheme,
  freshMap,
  onSelectStar,
  onSelectLantern,
  onSelectTeam,
  onSelectSign,
}) => {
  const theme = SKY_THEMES[skyTheme] || SKY_THEMES.deepnight;
  const stars = useMemo(
    () => messages.filter((m) => m.type === 'star' && m.position),
    [messages]
  );
  const lanterns = useMemo(() => messages.filter((m) => m.type === 'lantern'), [messages]);
  const starfield = useMemo(() => makeStarfield(20261019, 95), []);

  const [reduceMotion, setReduceMotion] = useState(
    () =>
      typeof window !== 'undefined' &&
      window.matchMedia?.('(prefers-reduced-motion: reduce)').matches
  );
  useEffect(() => {
    const mq = window.matchMedia('(prefers-reduced-motion: reduce)');
    const onChange = (e) => setReduceMotion(e.matches);
    mq.addEventListener?.('change', onChange);
    return () => mq.removeEventListener?.('change', onChange);
  }, []);

  // Density guard: keep twinkle/bob cheap on low-end phones.
  const animateObjects = stars.length + lanterns.length <= 150;

  return (
    <div data-sky-surface className="absolute inset-0 overflow-hidden">
      {/* Theme bands: solid colors so `transition-colors` actually animates
          (CSS gradients do not interpolate). */}
      <div
        aria-hidden
        className="absolute inset-0 transition-colors duration-1000"
        style={{ backgroundColor: theme.bg }}
      />
      <div
        aria-hidden
        className="absolute inset-x-0 bottom-0 h-[64%] transition-colors duration-1000"
        style={{
          backgroundColor: theme.mtnFar,
          maskImage: 'linear-gradient(to top, black 55%, transparent 100%)',
          WebkitMaskImage: 'linear-gradient(to top, black 55%, transparent 100%)',
        }}
      />
      <div
        aria-hidden
        className="absolute inset-x-0 bottom-0 h-[40%] transition-colors duration-1000"
        style={{
          backgroundColor: theme.mtn,
          maskImage: 'linear-gradient(to top, black 62%, transparent 100%)',
          WebkitMaskImage: 'linear-gradient(to top, black 62%, transparent 100%)',
        }}
      />
      <style>{`
        @keyframes lanternBob {
          0%, 100% { transform: translateY(0); }
          50% { transform: translateY(-6px); }
        }
      `}</style>

      <div aria-hidden className="pointer-events-none absolute inset-0">
        {starfield.map((s, i) => (
          <span
            key={i}
            className="absolute rounded-full bg-white"
            style={{
              left: `${s.x}%`,
              top: `${s.y}%`,
              width: s.size,
              height: s.size,
              opacity: s.opacity,
              animation: reduceMotion
                ? undefined
                : `splashStar ${s.dur}s ease-in-out ${s.delay}s infinite alternate`,
            }}
          />
        ))}
      </div>

      <Moon2D skyTheme={skyTheme} />

      <div className="absolute inset-0">
        {stars.map((m) => {
          const p = messageTo2D(m);
          return (
            <Star2D
              key={m.id}
              message={m}
              x={p.x}
              y={p.y}
              selected={m.id === selectedId}
              fresh={!!freshMap[m.id]}
              animate={animateObjects}
              reduceMotion={reduceMotion}
              onSelect={onSelectStar}
            />
          );
        })}
        {lanterns.map((m) => {
          const p = messageTo2D(m);
          return (
            <Lantern2D
              key={m.id}
              message={m}
              x={p.x}
              y={p.y}
              selected={m.id === selectedId}
              fresh={!!freshMap[m.id]}
              animate={animateObjects}
              reduceMotion={reduceMotion}
              onSelect={onSelectLantern}
            />
          );
        })}
      </div>

      <Terrain2D
            skyTheme={skyTheme}
            reduceMotion={reduceMotion}
            onSelectTeam={onSelectTeam}
            onSelectSign={onSelectSign}
          />
    </div>
  );
};

export default Sky2D;
```
